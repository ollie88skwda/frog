The Lab Notebook

Same Quiet-Instrument foundation, reframed as a science notebook: every session is a dated experiment entry — Conditions (the inputs you controlled) at the top, the procedure (your sets) below, and Findings (correlations across your history) as the payoff. The cues are borrowed from outside fitness — lab notebooks, terminals, Bearable/Oura — so it reads as an instrument, not another gym app. It still collapses to dead-simple: log nothing and it's a clean tracker; log everything and it's a controlled experiment.

Cue · Structure
Conditions → Procedure → Findings. The scientific method as the app's spine. Inputs vs. outputs, made visual.
Cue · Type
Mono numerals + units always shown (kg, g, h, mg). Reads like an instrument readout. Small-caps figure labels.
Cue · Annotation
Notes render as // comments — the lab/code-notebook tell. Quiet, optional, unmistakably "logbook".
Cue · Texture
Faint graph-paper grid on headers only — engineering-pad feel, never behind data (keeps numbers legible).

What changed vs. the first mockup

Same dark instrument base, but the structure now tells a scientific story: a Conditions header, // annotations, graph-paper headers, a cyan "signal" accent, and a new Findings tab that turns logged variables into correlations.

Accent shift

Swapped the warm fitness-orange for a clinical signal cyan #22D3EE, with green/red reserved for positive/negative correlations. Reads "instrument," not "gym." (Orange is still on the table.)

Scope note

Logging conditions = MVP (custom, typed, collapsible — like the per-set metrics). The Findings/correlation engine is a fast-follow: it needs accumulated history to say anything, so it naturally arrives after you've logged a few weeks.

Stays simple

Every science feature is opt-in. A user who logs only reps×weight sees a clean tracker. The notebook depth reveals itself only to those who want to control their variables.
